## Human-Led scenario matrix — approved source cases

| Source | Candidate test | Intent |
|---|---|---|
| US-001 S1 | `Should_OpenHeadOfficeArea_When_HeadOfficeUserSignsIn` | A single-role Head Office User reaches the protected catalogue landing. |
| US-001 S2 | `Should_OpenManagerArea_When_SalesManagerSignsIn` | A single-role Sales Manager reaches the manager landing. |
| US-001 S3 | `Should_OpenRepArea_When_FieldSalespersonSignsIn` | A single-role rep reaches the rep website landing. |
| US-001 S4 | `Should_OpenLastPermittedArea_When_StaffHoldsSeveralRoles` | One sign-in opens the last-used manager area and allows switching to head office without another sign-in. |
| US-001 S5 | `Should_OfferAreaChoice_When_MultiRoleStaffHasNoLastUsedArea` | First use offers only held areas; choosing one opens it in the same session. |
| US-001 S6 | `Should_SkipRemovedLastUsedArea_When_StaffSignsIn` | An unheld last-used area is ignored and the sole remaining area opens. |
| US-001 S7 | `Should_DenyStaffAccess_When_AnInactiveAccountAttemptsSignIn` | Rejection shows a retry state and opens no staff area. |
| US-001 S8 | `Should_EndStaffAccess_When_TheUserSignsOut` | Sign-out returns to entry and a protected page requires sign-in again. |
| US-002 S1 | `Should_OpenRepArea_When_RepFollowsPermittedLink` | A rep's direct link to the rep area succeeds. |
| US-002 S2 | `Should_DenyUnheldArea_When_AStaffMemberUsesADirectLink` | A direct head-office read or action shows no restricted content or action surface. |

The ten source cases above were approved on 2026-09-28, including denial of protected content
and actions. The names and one-line intents are the implementation matrix. Additional direct-link
return and Head Office User `/Admin` separation tests remain candidates for a later increment
review. WI-003 owns current-role checks after a role changes during an already-open session.
