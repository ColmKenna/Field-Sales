## Findings

- `followUpOf` is already a reserved optional section of the Call contract (version 1).
- The server checks a Call's structure only; the link needs one nullable column on `ReceivedCalls`.
- No screen shows a stock level.
- WI-055's "Record a follow-up call" opens a plain new call; this item points it at the follow-up (amends WI-055 scenario 8).

## Approved decisions

- **D1 Link:** `TabletCall` gains optional `followUpOf`. Server stores it in `ReceivedCall.FollowUpOf` (nullable, migration
  `AddFollowUpOfToReceivedCalls`); refuses an empty link or a link to itself; the original needn't have arrived first.
- **D2 Follow-up mode:** Record call at `/locations/{id}/calls/{callId}/follow-up`: "Follow-up call", "Following up your call on Tue
  22 Sep"; own channel (none preselected) and date; stock section starts **empty** (Add product in person, filter-or-search on Phone);
  notes, Add to order and Open order as a new call. `CallStore.Save(..., followUpOf)` refuses a link to a call this tablet doesn't
  hold at the same shop. After saving, back to the shop with "Call saved". Draft kept separately (a call being recorded or edited
  at the shop isn't lost).
- **D3 Entry points:** "Record a follow-up call" on Edit Call and the call page (unsent, sending or sent) opens the follow-up for
  that call. A follow-up of a follow-up links to the call it was opened from.
- **D4 Current stock level:** `StockReadings.Current(calls)` in the shared call contracts: per product, the count on the call saved
  latest (instant; never upload/receive order or date); ties by call id; counted entries only (Out = 0 counts; Not checked and
  Low-only don't); both readings stay. No screen uses it yet.
- **D5 Suggested List:** last check = newest In-person call that isn't a follow-up and has stock entries, plus every product on its
  follow-ups (and theirs). A follow-up never becomes the last check. No snapshot contract change.
- **D6:** a follow-up to a sent call is a new Unsent call.
- **D7 Out of scope:** Visit Due completion (S3, E13), campaign outcomes later (E20), showing stock level on a screen, reaching sent
  calls from the shop (WI-075).
- **D8 Finish:** push, PR, merge after CI (merge commit, branch kept), update local main.
