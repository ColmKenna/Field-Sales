## Approved decisions

- Classification is optional. Alternative brands require a primary brand, with the exact
  field error "Choose a primary brand first".
- Preserve the existing allowance for the same brand in both roles; usage counts a product once.
- Reject repeated alternative brand IDs. Keep existing archived references unchanged, reject
  new archived references, and permit clearing or replacing them with active references.
- One classification form and transactional save cover profile, primary/alternative brands,
  supplier and restriction group together. A rejected submission changes none of them.
- Follow the existing record order: price, unit, ranges, replacements, classification, attributes.
- Reuse existing relationships, migrations, usage sources and HeadOfficeCatalogue authorization.
  No new schema is expected. Do not change the already-approved restriction visibility rule.

## Approved scenario matrix

1. Save Chilled/SunCo/GlowCo/Irish Health Supplies/no group; show all and persist after restart.
2. Reject alternatives without a primary, including clearing a primary while alternatives remain;
   show the exact message and leave every classification unchanged.
3. Allow one brand in both roles and count the product once.
4. Reject repeated alternative IDs.
5. Assign, replace and clear a restriction group; at most one is stored.
6. Archived references of each type stay labelled and cannot be newly selected.
7. Retain unchanged archived references; replace or clear them successfully.
8. Reject a selection archived/deleted after page load without partial changes.
9. Reference-list usage counts follow assignment, replacement and clearing.
10. Invalid IDs, removed/missing roles and expired sessions write nothing and never replay.
11. Classification, price and unit forms work independently and preserve each other's data.
