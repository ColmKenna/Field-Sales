  manager save, new/moved/renamed Location, assignment/version or target archive;
  changed preview is shown and must be confirmed again.

  revoked role/team/eligibility cannot save; trustworthy changed labels refresh.

  no direct add/remove bypass or replay to another command/actor; no history.
- Should_SaveAtMostOnce_When_ConfirmIsRepeatedOrConcurrent → no duplicate assignment
  or history; conflicts refresh/fail without partial writes.
- Should_RollBackAndRetryExactlyOnce_When_SaveFailsAfterHistoryStaging → preview
  equality does not weaken existing atomic rollback behavior.
- Should_ShowExpandableCountsAndNamedActions_When_ManagerOrHeadOfficeReviews →
  Razor/BFF auth, current eligible choices, sources, cancel and zero state; CSRF,
  stale refresh, unavailable identity and no automatic save covered.
