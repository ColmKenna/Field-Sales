## Approved behavior

- Every grant in a cohort succeeds or fails together; forbidden, invalid or stale rows reject it all.
- Already-granted rows cannot be selected. Forged or stale submissions return conflict, with no
  duplicate record and no partial grant. Every selected row carries its expected last change id.
- Empty, duplicate or malformed selections are validation errors.
- WI-029's own-manager/Head-Office rule and self-change prohibition remain authoritative.
- Only active Field Salespersons can be granted. Inactive current holders stay visible, locked.
- Active group chooser; direct archived group pages are view-only, with no new grants.
- Optional reason uses WI-029 trimming, 1000-character and control-character rules.
- Trusted identities are resolved before transactions. Lock selected reporting lines through the
  catalogue commit. Process selected subjects in deterministic order. One timestamp per action.
