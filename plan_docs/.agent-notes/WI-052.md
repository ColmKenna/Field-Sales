- `LowItems.Of(IEnumerable<CallStockEntry> marked, TabletOrder? order, IReadOnlySet<Guid> takenOff)`: for each entry with `Low`, in the

## Approved decisions

- **D1 Tabs:** two tabs now: `Order pad` (today's content exactly, search box included) and `Low (n)`. "Search all" waits for Ranges to
  split the pad from the catalogue.
- **D2 From a call:** Record call gets **Open order**: opens the order WI-051's find-or-create would pick, or a new one. Order entry
  opened this way knows the Call; its back link reads **Back to call** (the draft is restored as on any resume).
- **D3 Which order a line goes on:** order entry always adds to the order on screen; opened from a Call, a new order gets the Call's id
  on its first line (pad or Low tab), via a new `AddLine(..., callId)` overload on the same locked step. Standalone orders stay unlinked.
- **D4 Which Call's Low items:** the Call order entry was opened from, else the order's `callId`; from its draft while being recorded,
  from the saved Call afterwards. No Call: `Low (0)` and "No stock check with this order." (carry-over and Record call link: T-5.1.5).
- **D5 State derivation:** one function over the Call's Low lines and the order. ADDED (qty) whenever the product has a line on the
  order; REMOVED when not on the order and the Call recorded its line was taken off this order; not added otherwise. The only stored fact
  is "taken off", a set of product ids on the Call draft, recorded on line removal or order deletion in order entry. Re-adding wins.
  Limit: after the Call is saved, a removed item reads not added.
- **D6 Rows:** name, state (`not added`, `ADDED - 24`, `REMOVED`), a second line ("counted 3" / "not counted" / "you took this off the
  order"); Add on not added and REMOVED opens WI-051's `QuantityPopover`, closing back to the tab. ADDED shows the quantity only (change
  stays on the order lines). No Add all.
- **D7 Count:** `Low (n)` counts not added only (CAN'T ADD joins with E8). Unticking Low drops the item from the tab and leaves the
  order line (S13).
- **D8 Out of scope:** T-5.1.5 carry-over, REPLACED (E10), CAN'T ADD (E8), a stepper on ADDED rows, Search all. No server or contract
  change.
- **D9 Finish:** push, PR, merge after CI (merge commit, branch kept), update local main.
