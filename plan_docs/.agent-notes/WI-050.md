## Approved decisions

- **D1:** `CallStockEntry` gains the reserved optional `low` (true or absent). Out = Low + count 0, no field of its own; "(k out)" counts
  Low entries with count 0. Call stays version 1.
- **D2:** a Phone call saves only touched rows (Low/Out or a count); untouched rows aren't saved, never Not checked.
- **D3:** a Low mark counts as recording something on either channel.
- **D4:** review "Phone · 2 marked Low (1 out)" ("(… out)" omitted when 0); counted-not-Low rows add "· 1 counted"; the section
  header shows the same counts, blank when nothing marked.
- **D5:** Low marks are kept and saved on an In-person Call too; In person shows a read-only "Low"/"Out" note and the review adds
  "· 2 Low" (S3), until WI-051's tick. Counts carry both ways (Out shows 0 in person).
- **D6:** Out sets Low + count 0 (replacing a count); Out off removes the 0, keeps Low; Low off also clears Out. Add count opens a box
  (no stepper) with the shared checks; clearing it returns the row to untouched unless Low.
- **D7:** one "Filter or search" box narrows rows by name/code (order-search matching); with no match, catalogue results with Add; the
  product becomes a row. No separate Add product button on Phone.
- **D8:** server accepts `low`; refuses a Phone entry with neither count nor Low as `incomplete` (inferred). Phone never counts as the
  last stock check (WI-049 D4).
- **D9:** finish = push, PR, merge after CI (merge commit, branch kept), update local main.
