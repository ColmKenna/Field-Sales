## Findings

- `competitorNotes` is a reserved optional section of the Call contract (version 1); `CallContract.RecordSomething` already reads
  "Add pitch notes, a stock check or a competitor note".
- The snapshot has no Ranges until E9; categories are in the product index (`PadCategory`, breadcrumbs via the order pad).
- `CallStore.Correct` copies the saved Call with `with`, so fields it doesn't set survive; its `content.Problem` check must see the
  notes, or a Call recording only notes couldn't be corrected.
- The server keeps stock entries as ids in `ReceivedCallStockEntries`, names only in the received body.

## Approved decisions

- **D1 Note model:** optional `competitorNotes` on `TabletCall`; each note: id, text, one link type (None, Products 1+, Range 1,
  Category 1). Links keep their captured name (archived Ranges keep their label).
- **D2 Content:** a note counts as recorded; save review ends "1 competitor note" / "3 competitor notes". Text required, up to 4,000
  characters (inferred). No pick for the type: "Tick at least one product, or link to None" / "Choose a category, or link to None" /
  "Choose a range, or link to None".
- **D3 Record call:** collapsed "Competitor notes (N)" after Pitch notes; each note: "What did you see?", Link to (four options), the
  picker, Remove; "Add competitor note". Kept through a resume; same on new calls and follow-ups.
- **D4 Pickers:** Products — this call's products with a count or a Low mark first, then search of the downloaded products (restricted
  never downloaded; unavailable and outside-range linkable). Category — filter over downloaded categories with breadcrumbs. Range —
  "No ranges on this tablet yet" until E9; archived never offered.
- **D5 Switching:** with picks, asks "Switching will remove 2 linked products" (or "…the linked category" / "…the linked range"),
  Switch or Cancel; Cancel keeps them. No picks: switches straight away.
- **D6 Edit Call:** note text changes, notes can be removed; links stay; no Add competitor note. Storage refuses a new note, changed
  links or blank text. A Call recording only notes can still be corrected. Completes US-015 S2.
- **D7 Call page:** lists each note with its links.
- **D8 Server:** tables `ReceivedCallCompetitorNotes` and `ReceivedCallCompetitorNoteProducts`, migration
  `AddCompetitorNotesToReceivedCalls`. Structure check refuses blank or too-long text, unknown link type, link fields not matching the
  type, Products with none or repeats, Range/Category without an id, repeated note ids. Names stay in the received body.
- **D9 Out of scope:** Ranges (E9), competitor reporting, prospects (WI-173).
- **D10 Finish:** push, PR, merge after CI (merge commit, branch kept), update local main.
