## Approved decisions (D1 as revised)

- **D1 Link (revised 2026-11-04):** `TabletOrder.CallId`. See Current state.
- **D2 Find-or-create:** the Call's linked In Progress order, else the rep's most recently saved In Progress order at the shop, else new;
  chosen and added in one step under the per-rep `OrderStore` gate. If the linked order left In Progress, the next add finds/creates
  another, and a new one is linked to the Call.
- **D3 In person:** Low tick on every row; ticking shows Add to order; unticking keeps the count. Phone keeps WI-050 D6.
- **D4 Phone:** Add to order active on every row, doesn't mark Low; a row only on the order isn't a stock entry.
- **D5 "On order (N)":** replaces Add to order when the product is on the Call's order (linked or found), incl. order-entry lines;
  measures show the unit. Unticking Low leaves the line.
- **D6 Popover:** as built above. "list price" on screen; lines keep "Base price".
- **D7 Reusable component:** `QuantityPopover.razor`, reused by the Low tab (T-5.1.4).
- **D8 Leaving unsaved** keeps added lines; leave dialog says so.
- **D9 Server (revised):** nothing new; it already stores `ReceivedOrders.CallId`. Out of scope: Low tab, break prompts, E10, S5/E9, S9, S13.
- **D10 Finish:** push, PR, merge after CI (merge commit, branch kept), update local main.
- **Order-only Call:** not saved (S5 rule).
