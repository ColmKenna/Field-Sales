criteria. Enumerating them here also satisfies the console's scenario-agreement

- Mixed Region/County/Town/Location assignments appear by level with stable IDs,
  names and directly assigned labels; effective summary counts unique Locations.
- Wicklow has 140 Locations; Rathdrum has 23 carved out to Aoife; expansion shows
  every Town and its total; Colm's Primary count is 117 before any extra override.
- A direct Location override does not mislabel an entire Town as carved out;
  same-rep narrower assignments do not count as lost ownership; multiple owners
  and overlapping geography do not inflate the effective total.
- Empty rep, zero-Location County/Town, archived assigned geography and duplicate
  geographic names retain correct counts, context and stable identity.
- Filtering finds Towns inside Counties and preserves parent context; it never
  changes the rep's overall Primary total. Native disclosure remains usable by
  keyboard and carve-outs are communicated in text.
- Manager reads/edits their own rep only; foreign-rep direct link and forged POST
  denied; Head Office can act on any rep; role/reporting-line changes take effect
  on the next request and again at save. Trusted identity failure is explicit.
- Add and Remove navigate from the rep page into existing preview/confirm;
  Cancel writes nothing; success returns to updated counts; stale input replaces
  preview without saving; retry requires another confirmation; CSRF stays enforced.
- Reads/filter/disclosure write no assignments or history. Assert named source
  ownership and database state, not merely markup or HTTP success.
