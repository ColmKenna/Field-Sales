## Approved decisions

- **D1 Call page:** read-only `/locations/{id}/calls/{callId}` (date, channel, notes, stock lines: counted N / not checked / Low).
  Sync's Unsent review of a call gains **Open call**. Unsent: **Edit call** and **Record a follow-up call**. Sent: **Record a
  follow-up call** only (S4). Sent calls get an entry with WI-075.
- **D2 Edit Call:** Record call in edit mode at `/locations/{id}/calls/{callId}/edit`, titled "Edit call". Allowed: channel; a counted
  line's count to another valid count (not cleared — Remove drops it); Low tick/untick; Out on a phone row only where it already has a
  count; notes edited or cleared only if the call had notes; Remove on any line. Not offered: Add product, catalogue search, category
  browse, Add count, a count on a Not checked line, Pitch notes opener when none, Add to order, Open order, Delete.
- **D3 Follow-up offer:** **Record a follow-up call** where Add product was (and where Pitch notes would be when none). Opens Record
  call at the shop for a new call; WI-056 adds the link.
- **D4 Saving:** review "Save changes?" with the summary, Back and Save; same checks as recording. `CallStore.Correct` enforces D2's
  rules too, keeps id, date, saved time, rep and snapshot and the Unsent queue place, refuses a call sent, being sent, refused, or for
  another shop. Returns to the call page.
- **D5 Claims:** the uploader claims calls as it does orders. A call being sent shows "This call is being sent. Sync again before
  changing it." and no Edit call. Needs Attention calls keep WI-042's handling, no Edit.
- **D6 Unsaved edits:** survive a resume, kept apart from a call being recorded at the same shop; Back with changes asks Leave/Stay;
  leaving keeps the saved call as it was; unticking Low never touches the order (T7.8).
- **D7 Out of scope:** the follow-up link (WI-056), sent-call view and entry (WI-075), website corrections (WI-120/E13), competitor
  notes (T-5.8.1), Visit Due completion (E13), Needs Attention calls.
- **D8 Finish:** push, PR, merge after CI (merge commit, branch kept), update local main.
